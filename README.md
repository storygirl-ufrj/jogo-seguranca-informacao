# Jogo de Tabuleiro Digital: Segurança da Informação 🛡️🎲

Este projeto é um jogo de tabuleiro digital voltado para ensinar e testar conhecimentos sobre segurança da informação. Desenvolvido em dupla com a @dupla como parte de um desafio laboral do projeto StoryGirl.

## Objetivo
Promover o aprendizado de boas práticas de segurança digital por meio de uma experiência lúdica e interativa.
